## Test/misc generated images

When generating an image during testing, debugging, or verification (not tied to a real chat
message or feed post), save it to `roleplay_app/frontend/public/generated/misc_{random_num}.jpg`
- not to a scratchpad or temp directory - so it's easy for the user to find and review
afterward. Pick `{random_num}` so it doesn't collide with an existing file in that folder.
